# Bàn giao sổ ghi chú

| Mục | Trạng thái | Cách tiếp tục |
|---|---|---|
| Repo riêng | Thiếu | Nhận lịch sử từ `so-ghi-chu.bundle` trong artifact của lượt chạy. |
| Xem bản dev | Loopback của runner | Clone bundle, theo README sản phẩm và chạy `bash tests_e2e/preview.sh` trên máy có Docker Compose. |
| Duyệt MVP | Chờ quyết định cho SHA đã trình | Xem `docs/autopilot/STAGE.json` và thử đăng nhập, tạo, mở phiên mới rồi đọc lại. |
| Production | Chưa cấp quyền hoặc đích cho sản phẩm này | Chủ dự án chọn đích và grant cho đúng sản phẩm trước khi phát hành. |
